# Agent Instructions

These instructions apply to the entire repository.

## Mandatory Release Notes

- Every project change must update `RELEASE_NOTES.md` in the same change set.
- This rule applies to Codex, Antigravity/antygravity, OpenCode, WorkBuddy, and any other AI agent working in this repository.
- Use the current project version from `WinLauncher/version.h`. If the version has not changed, update the existing section for that version. If the version changes, add a new section at the top.
- Write release-facing copy for users, not code-level implementation notes.
- Do not duplicate entries inside the same version section. Merge overlapping notes into one clearer item.
- Record feature additions, behavior changes, bug fixes, visual changes, documentation updates, release preparation, and maintenance work.
- Before finishing a task, check that `RELEASE_NOTES.md` reflects the actual changes made.
